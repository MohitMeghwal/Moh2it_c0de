# Moh2it c0de
A simple installable PWA for editing HTML/CSS/JS and previewing the result.

## GitHub Pages
1. Upload `index.html`, `manifest.json`, `sw.js`, and `icon.svg` to a GitHub repository.
2. GitHub → Settings → Pages → Deploy from branch → select the branch/root.
3. Open the HTTPS GitHub Pages URL on Android Chrome.
4. Use Chrome menu → Add to Home screen / Install app.

## Features
- Project-based workspaces
- localStorage saving
- Separate Code and Preview screens
- Search + next/previous match with direct cursor jump
- Mobile / Desktop / Full preview
- Quick Preview without creating a project
- Rename, duplicate, delete
- JSON export/import
- Offline cache after first successful load
- Responsive mobile-first UI
